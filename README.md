# Physics Simulations and Personal Projects
This is for my simulations of physical systems or for any personal projects I might be working on!
# What's in this:
1. An Ising model simulation using the renormalization group method, with code to observe change with temperature and coupling variable. (Senior Thesis)
2. A metropolis monte carlo algorithm of the ising model using only nearest neighbors. (Senior Thesis)
3. A quantum shooting method simulation to look for the ground state energies of a schrodinger equation problem.
4. A simulation which is done to observe the precession of the perihelion of mercury. This is done as a many-bodied simulation including Saturn, Jupiter, Earth, alongside Mercury.
